# OpenSLD GridPilot redesign

Static prototype of the OpenSLD editor interface. Open `index.html` in a browser to view it locally.

The site uses HTML, CSS, JavaScript, and bundled assets. No build step is required. Interface edits are stored in the viewer's browser with `localStorage`; they are not shared across visitors.

To publish with GitHub Pages, set the repository's Pages source to **Deploy from a branch**, branch **main**, folder **/(root)**.
